# База правових позицій Верховного Суду (lpd.court.gov.ua)

Автор: В'ячеслав Плескач

Відкрита копія [Бази правових позицій Верховного Суду](https://lpd.court.gov.ua/) разом із дайджестами та оглядами судової практики ВС. Дані беруться з відкритого API сайту (`https://lpd-api-prod.court.gov.ua/api/v1`) і впорядковуються за вагою практики: **зразкові справи → Велика Палата → об'єднані палати → палати → колегії суддів**.

Стан на 23.11.2026: 14 645 правових позицій, 17 195 рішень, до яких вони прив'язані, 78 рішень ЄСПЛ, 896 дайджестів і оглядів (27 434 пункти змісту).

## Рівні практики

Окремої позначки «ОП» чи «палата» на сайті немає, тому рівень визначається так (поле `riven`, `riven_nazva`):

1. **Зразкова справа** — рубрики «Зразкові справи» (ВП) і «Зразкові рішення» (КАС) або назва «Зразкова справа…».
2. **Велика Палата** — тег сайту «Велика Палата», суд рішення 9951 або склад «Велика Палата» в шапці рішення.
3. **Об'єднана палата** — рубрики «Постанови Об'єднаної Палати» (КЦС, КАС), склад «Об'єднана палата» в шапці рішення, для ККС — рубрика «ОБ'ЄДНАНА ПАЛАТА, ПАЛАТА» разом зі згадкою ОП у тексті.
4. **Палата** — рубрики судових палат КАС; рубрика ККС «ОБ'ЄДНАНА ПАЛАТА, ПАЛАТА» без згадки ОП (позначено «Палата або ОП (ККС, уточнити за рішенням)»).
5. **Колегія суддів** — решта.

Склад суду з шапки рішення поки встановлено для 236 із 17 195 рішень: сервер віддає повні тексти повільно (≈1 рішення за 1–4 с). Решту шапок дозбирують поступово регулярні оновлення (`--docs`). У КГС немає рубрики ОП, тому позиції ОП КГС виявляться лише після цього.

Позначки сайту: **«З відступом»** — нова позиція, у тексті якої зазначено, від якого висновку відступлено; **«Змінено»** — позиція, від якої вже відступлено (у тексті вказано нове рішення).

## Пошук

```bash
python3 scripts/poshuk.py "дисциплінарн* скарг*" --riven 2          # зразкові + ВП
python3 scripts/poshuk.py "строк* звернення" --sud КАС --riven 4
python3 scripts/poshuk.py --sprava 990/61/26
python3 scripts/poshuk.py "відступ*" --poznachka
python3 scripts/poshuk.py "електронн* доказ*" --dajdzhesty            # пункти змісту дайджестів
python3 scripts/poshuk.py "істотн* дисциплінарн* проступ*" --dajdzhesty --tekst   # повні тексти, зі сторінками
```

## Оновлення

```bash
python3 scripts/lpd_sync.py --docs 600 --docs-minutes 25   # позиції, рубрики, рішення, ЄСПЛ, перелік дайджестів + шапки рішень
python3 scripts/digest_sync.py                             # нові PDF дайджестів, зміст, каталог
```

Потрібні Python 3.9+, `pdftotext` (poppler-utils), за бажанням `pypdf`. PDF дайджестів у репозиторій не входять (≈610 МБ), тексти — входять.

Особливості API, які враховують скрипти:
- список позицій (`/legal-position/recent`) не містить номерів справ — вони беруться з `/document/list`;
- поле `total` у відповідях завищене; кінець даних — порожня сторінка;
- у старих записів однакова (порожня) дата затвердження, тож сторінки можуть «з'їжджати»: дублікати відкидаються, а позиції, яких бракує порівняно з попереднім знімком, дозапитуються поштучно;
- у старих рішеннях дата (`adjudication_date`) збережена з UTC-зсувом на добу назад; береться `law_date` або виправлена дата;
- повний перелік дайджестів (896) дає порожній запит до `/digest/search`; навігація сайту явно містить лише 355 з них, решта — періодичні, що підбираються за тегами.

## Застереження

Це неофіційна копія. Чинний текст позиції і рішення — на lpd.court.gov.ua і в ЄДРСР. Зміст дайджестів виділено автоматично: у 878 із 896 документів він є, у 18 його виділити не вдалося; у частині старих оглядів замість змісту взято заголовки з тексту.
