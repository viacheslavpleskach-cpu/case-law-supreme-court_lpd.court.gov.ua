# Колегії суддів ВС за галузями права (автоматична розмітка)

Автор: В'ячеслав Плескач. 11908 позицій колегій з lpd.court.gov.ua. Галузь і тип питання визначено автоматично моделлю, навченою на перевірених позиціях зразкових справ, ВП, ОП і палат; розмітка приблизна. Позначка ? — низька надійність (галузь може бути визначена неточно; позицію додано також до галузі за правилами). Резюме немає; повний текст — `python3 scripts/poshuk.py --id <id>`.
